# public/social/

Instagram API'nin indirebilmesi için herkese açık video/görsel dosyaları.

Buraya konan dosya yayında şu adreste yaşar:

    https://atlasia.pages.dev/social/<dosya-adi>

**Dikkat:** Bu klasördeki her şey herkese açıktır. Özel veya lisanssız
materyal koyma. Yayınlandıktan sonra dosyayı silmek, Instagram'ın daha önce
yayınlanmış gönderisini etkilemez (Meta medyayı kendi CDN'ine alır).
