## Bulgular

**B1 — Rules emulator kanıtı bu ağaçta eksik (düşük, bilinen).**
Ortamda Java 21 yok; `npm run test:rules:emulator` doğru hata ile durdu.
Kuralların güncel hâli emulator ile bu dalda doğrulanmadı → P12 kapsamı.

**B2 — P11 allowlist daraltması bu dalda yok (orta).**
`isCacheableTile` (`offlineCache.ts:25-31`, `public/sw.js:19-22`) hâlâ
`url.includes("tiles.openfreemap.org")` vb. substring eşleşmesi kullanıyor.
`https://saldirgan.example/x?tiles.openfreemap.org` benzeri lookalike URL
cache'e alınabilir. Tam HTTPS host/path eşleşmesi `arena/fd127f10-atlasia`
dalında yapılmıştı; bu dal (main tabanlı) onu içermiyor. Plandaki P11
satırına şerh düşüldü. **Düzeltme kullanıcı kararına bırakıldı — P11'in
bu dala port edilmesi ayrı görevdir, bu denetimde yapılmadı.**

**B3 — P10 spin değişikliği bu dalda yok (bilgi).**
Spin döngüsü bu ağaçta `requestAnimationFrame` kullanıyor
(`MapView.tsx:655-657`). "15 FPS setTimeout" durumu `fd127f10` dalına
aitti. Plan bağlam notuna şerh düşüldü; performans iddiası her hâlükârda
profilsiz kurulamaz.

**B4 — `as any` tek kullanımı (düşük).**
`src/hooks/useFirestoreAtlasData.likes.test.ts:223` (+ aynı dosyadaki
sahte-IO katmanında `field: any`, `q: any` tiplemeleri). Üretim kodunda
`as any`/`@ts-ignore` yok; kural metni ("eklenmez") açısından test
dosyasında yine de aykırılık sayılabilir. P16 kapsamına bırakılması uygun.

**B5 — Büyük JS chunk uyarısı sürüyor (düşük, kayıtlı).**
Build 500 kB chunk uyarısı veriyor; P2 teslimatında da kayıtlı. P19 görevinin konusu.

**Not (tasarım):** `places/posts/stories/verifications` içinde
`allow get: if true` bilinçli karar (herkese açık okuma, liste boundedList
ile sınırlı; verifications yorumunda açıkça yazılı). Zayıflık olarak işaretlenmedi.
